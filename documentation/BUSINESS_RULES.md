# Business rules
Abandonment requires at least one line, no qualifying purchase, eligible open lifecycle, and last activity age >= 60 minutes. Consent is evaluated independently per EMAIL/SMS using latest effective_at <= decision time; only OPTED_IN permits contact. Unknown/opt-out are suppressed. Default cap: 3 attempts/customer/channel? The service helper currently evaluates max 3 recent customer attempts in 7 days and 24h minimum interval; cart-level duplicate recovery is blocked. Campaign variants: A=1h, B=6h, C=24h. Message provider is simulated; never send real communications. All suppressions should be recorded in audit_decisions by orchestration service.
